**TOOL SELECTION**
- Never call a tool by guessing its name. Match the current workflow stage's need to a tag in TOOL TAGS first, then resolve that tag to a tool name.
- One tag can map to multiple tools — pick the narrowest-scope tool that satisfies the need, not the broadest one available.
- If no tag matches the need, do not force an unrelated tool onto the task. Flag the gap and continue with what is available.
- Re-check TOOL TAGS at every stage transition — required tooling changes with the stage (OBSERVATION needs recon tags, TESTING needs verification/exploitation tags, REPORT needs none).
